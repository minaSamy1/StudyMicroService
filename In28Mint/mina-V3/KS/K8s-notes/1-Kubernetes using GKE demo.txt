4- connect to console 
	gcloud container clusters get-credentials my-cluster --region us-central1 --project glowing-anagram-451505-v3
5- create new Deployment 
     kubectl create deployment hello-world-rest-api --image=in28min/hello-world-rest-api:0.0.1.RELEASE
	 
6- expose our deployment to be external and Testing it.
     kubectl expose deployment hello-world-rest-api --type=LoadBalancer --port=8080

9- AutoScaling  number of Pods based usage
    kubectl autoscale deployment hello-world-rest-api --max=10 --cpu-percent=70

, Kubernetes will monitor the CPU usage of your pods in the hello-world-rest-api deployment,
 and it will automatically increase or decrease the number of pods to maintain a target CPU usage of 70%.
 
 
9: Add some application configuration for your microservice
	Config Map - kubectl create configmap todo-web-application-config --fromliteral=
	RDS_DB_NAME=todos

10: Add password configuration for your microservice
	Kubernetes Secrets - kubectl create secret generic todo-web-application-secrets-1 --
	from-literal=RDS_PASSWORD=dummytodos
    
12: Delete the Microservices
	Delete service - kubectl delete service
	Delete deployment - kubectl delete deployment
	
13: Delete the Cluster
    gcloud container clusters delete
