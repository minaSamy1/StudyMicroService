       ------------ currency-conversion ----------------------------------
	   -one of the usage of enviroment varaible is to define some variable in our project or project.properities
	      and take its value from Kubernetes it same as Environment in Docker-compose
		
	  - so we can apply it on currency proxy 
	      @FeignClient(name = "currency-exchange", url = "${CURRENCY_EXCHANGE_URI:http://localhost}:8000")
		
	    so we need to get value of CURRENCY_EXCHANGE_URI from k8s 
		
	  - so we build new image to be v12 and push it to docker hub
	     docker push docker.io/mina21/mmv3-currency-conversion-service:0.0.12-SNAPSHOT
		 
	 - so we need to make new deployment.yaml for currency-conversion  and using enviroment variable and
	      change the currency image version 
	   in deployment.yaml
	 spec:
      containers:
      - image: mina21/mmv3-currency-conversion-service:0.0.12-SNAPSHOT
        imagePullPolicy: IfNotPresent
        name: mmv3-currency-conversion-service
        env:
         - name: CURRENCY_EXCHANGE_URI
           value: http://currency-exchange
      restartPolicy: Always

   11- knowing the useful of config map to store the environment variable
             -------- currency-conversion----------------------
		@FeignClient(name = "currency-exchange", url = "${CURRENCY_EXCHANGE_URI:http://localhost}:8000")
		instead we define the variable in we can define it in sperated object ConfigMap
        so our yaml will contain 3 section  ( deployment , service , configMap)
		   1- in deployment section we will map to our configMap object by add (  envFrom ) section
		   
		     spec:
			  containers:
			  - image: mina21/mmv3-currency-conversion-service:0.0.12-SNAPSHOT
				imagePullPolicy: IfNotPresent
				name: mmv3-currency-conversion-service
				envFrom:
				  - configMapRef:
					  name: currency-conversion


        2- creating configMap object in side our deployment
                		http://currency-exchange  where it's the deployment name
		apiVersion: v1
		data:
		  CURRENCY_EXCHANGE_URI: http://currency-exchange  
		kind: ConfigMap
		metadata:
		  name: currency-conversion
		  namespace: default

   13- knowing about liveess and readless 
      we use spring actutor with mircoservice to know the health about the api 
	  and adding some section to our deployment object 
	    
		   spec:
      containers:
      - image: mina21/mmv3-currency-exchange-service:0.0.11-SNAPSHOT
        imagePullPolicy: IfNotPresent
        name: mmv3-currency-exchange-service
        readinessProbe:
          httpGet:
            port: 8000
            path: /actuator/health/readiness
        livenessProbe:
          httpGet:
            port: 8000
            path: /actuator/health/liveness
